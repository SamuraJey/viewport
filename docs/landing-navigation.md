# Landing navigation

The landing page header exposes the **Log in** link to `/auth/login` at every
viewport width, including phones. It remains next to the readability and theme
controls, with a minimum 44px touch target and the same light/dark theme styling.

Header items can wrap onto another row on narrow screens or with enlarged text
so the login link and settings controls remain accessible without clipping.
The section navigation (Features, Workflow, Plans, FAQ) appears on desktop.

The mobile hero uses a width-bounded single-column grid, and the preview header
can wrap. This keeps enlarged text from widening the hero beyond the viewport
and being clipped by the landing page's decorative overflow container.
